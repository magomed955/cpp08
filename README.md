# CPP Module 08

CPP Module 08 is part of the C++ modules in the 42 curriculum and focuses on templated containers, iterators, and algorithms. The project involves working with the Standard Template Library (STL), implementing custom container behavior, and using iterators to manipulate collections of data efficiently. It strengthens understanding of generic programming, container design, iterators, and the use of STL algorithms in C++.

**Technologies:** C++, STL, Containers, Iterators, Templates, Algorithms, Makefile, Git.
